# 2027 年中国大陆放假与调休补班日历

按中国大陆官方安排制作，供 iPhone 在线订阅。两个日历每天一条全天日程，不设置事件提醒。

- **放假日历（绿色）**：29 天，仅包含官方公布的完整放假区间，不额外标记普通周末。
- **调休补班日历（红色）**：5 天，标题明确标注“调休上班”。

## iPhone 在线订阅

在 iPhone 的“日历”App 中，依次打开“日历 → 添加日历 → 添加订阅日历”，分别粘贴以下两个 HTTPS 地址。

### 放假日历：选择绿色

```text
https://raw.githubusercontent.com/lvshuaishuai888/adrule/main/calendar/2027-holidays.ics
```

### 调休补班日历：选择红色

```text
https://raw.githubusercontent.com/lvshuaishuai888/adrule/main/calendar/2027-workdays.ics
```

输入地址后，轻点“查找”或“订阅”，确认名称并选择对应颜色，完成添加。如需同步到其他 Apple 设备，将账户选为 iCloud。颜色以 iPhone 中的设置为准，文件中的颜色提示可能不会自动应用；以后可在日历列表中轻点对应日历旁的 ⓘ 修改。

如不需要提醒，可在日历设置中关闭“日程提醒”。[Apple 官方订阅说明](https://support.apple.com/zh-cn/102301)。

请使用上面的 Raw 地址，而不是 GitHub 文件预览页面地址。订阅可接收本仓库文件的后续修改，但刷新时间取决于日历客户端及网络缓存，不保证即时更新。本目录仅提供 2027 年安排，不自动增加以后年份。

使用 UTF-8 编码、CRLF 换行及 iCalendar 2.0 格式。事件以纯日期表示全天，结束日期为下一天，不因时区转换偏移。每条事件的 UID 由日期与类型确定；维护同一事件时保留 UID，更新 DTSTAMP、LAST-MODIFIED，并递增 SEQUENCE。
